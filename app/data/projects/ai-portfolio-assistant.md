Project: AI Portfolio Assistant
Rebecca built an AI-powered portfolio assistant using React, Python FastAPI, Google Gemini and ElevenLabs. The assistant helps visitors explore her skills, education, experience and projects through both typed chat and voice interaction. The backend uses a markdown knowledge base, secure environment variables, backend-only voice proxying and prompt rules to avoid exposing private or confidential information. This project demonstrates LLM integration, speech workflow design, API design, prompt engineering, full-stack architecture and user-focused AI product thinking.
